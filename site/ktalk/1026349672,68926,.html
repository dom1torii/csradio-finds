Discussing: Counter-Life Beta 2.5 coming soon... Back To CSR

{ Counter-Life Beta 2.5 coming soon... }
posted Wednesday, July 10, 2002 by Some1 Call 911
It seems Counter-Life has really pulled their asses from the ground and actually started bringing Counter-Life back to life. Anywhoo, what's new?

  • Added Steyr Aug
  • Added Benelli XM1014
  • Added Sig SG-550
  • Carry ammo for shotguns increase to 96 for you trigger-happy people out there
  • Fixed missing tank/sentry rockets
  • M4A1, SG552, Aug, SG550 and M249 now have the same max carry ammo
  • Made the G3SG1 slightly inaccurate
  • Fixed G3SG1 sprite problem
  • Sniper rifles now in slot 5, together with M249
  • Price for ammunition increased. Now $100
  • Up to 2 assault rifles can be held of each team class
  • Updated install-cs.bat. No need to copy 'talk.wav'
  • Fixed falling bug (forget about the elite method).
    The next version will be up either this week or next.

    Great. Let's hope it does get into our Half-Life folders this week and not delayed to the point where we all think Counter-Life died again.
