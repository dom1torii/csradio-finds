Discussing: StatsMe 2.6.4 Released Back To CSR

{ StatsMe 2.6.4 Released }
posted Friday, July 26, 2002 by Some1 Call 911
olo has released a new version of StatsMe. I believe CSR's official server uses StatsMe, So here's the changes:

  • statsme.cfg is automaticly executed (no need for "exec statsme.cfg" in server.cfg)
  • cvar: sm_refresh (by default set to 0, sets if config should be reloaded on map change)
  • cvar: sm_cfgfile (if you want to use other name for config just set this cvar in server.cfg)
  • cvar: sm_debug (allows to save engine messages to file - sm_debug_modname.txt)
  • cvar: sm_flood (set in seconds min. delay between each alias call)
  • sm_score < team name > < team name > - sets names of teams to score
  • say commands /stats, /statsme and /top15 are now changed to console commands there are also aliases to keep old style calling for stats
  • support for DoD (still has some problems with counting kills by grenades)
  • tweaks in scripts
    If you don't know what StatsMe is, it's basically a server-side module that reports damage you've inflicted and have been inflicted when the round is over. There's a little more to it, a good example to see this thing in action is to hop on the CSRadio Server and check it out.
